# ToDo List App

## 概要

JavaScript(Vanilla JS)で作成したToDo管理アプリです。
PCとスマートフォンの両方で快適に操作できることを意識して設計しました。
PCではドラッグ＆ドロップ、スマートフォンでは長押しによるドラッグ操作に対応しています。
モバイル操作時の誤作動を防ぐため、スクロールとドラッグが競合しないよう工夫しています。

## 主な機能

- タスクの追加・編集・削除
- 完了/未完了の切り替え
- タスクの並び替え
 - PC:ドラッグ＆ドロップ操作
 - スマートフォン:長押しによるドラッグ操作
- 上下ボタンによるタスク移動
- localStorage を利用したデータ保存(ページ再読み込み後も保持)
