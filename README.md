# ToDo List App

## 概要

JavaScript(Vanilla JS)で作成した ToDo 管理アプリです。
PC とスマートフォンの両方で快適に操作できることを意識して設計しました。
PC ではドラッグ＆ドロップ、スマートフォンでは長押しによるドラッグ操作に対応しています。
モバイル操作時の誤作動を防ぐため、スクロールとドラッグが競合しないよう工夫しています。

## デモ
https://yuji141.github.io/ToDoApp/

## 主な機能

- タスクの追加・編集・削除
- 完了/未完了の切り替え
- タスクの並び替え
  - PC:ドラッグ＆ドロップ操作
  - スマートフォン:長押しによるドラッグ操作
- 上下ボタンによるタスク移動
- localStorage を利用したデータ保存(ページ再読み込み後も保持)

## 工夫した点

### モバイル操作時の誤操作防止

スマートフォンでは、タップ操作とスクロール操作が頻繁に発生するため、
ドラッグ操作を「長押しした場合のみ有効」にしました。
これにより、意図しない並び替えが発生しにくい設計にしています。

### スクロールとドラッグ操作の競合対策

`touchstart` では `preventDefault()` を使用せず、
ドラッグが確定したタイミングでのみスクロールを抑制するようにしました。
これにより、通常のスクロール操作とドラッグ操作の両立を実現しています。

### PC とスマートフォンで操作方法を分離

PC ではマウス操作に適したドラッグ＆ドロップを採用し、
スマートフォンではタッチ操作に配慮した長押しドラッグを実装しました。
デバイスごとに最適な操作体験を提供することを意識しています。
